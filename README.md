# 🍔 Bite & Bun

**Bite & Bun** is a modern online food ordering web application where users can explore delicious food items, search their favorites, add to cart, and securely pay online. It features a smooth and intuitive UI, role-based authentication, and real-time cart management — all built with powerful modern tools.
